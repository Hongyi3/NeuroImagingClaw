# Benchmark Metrics

## Operational metrics

- conversion completion rate
- validation pass/warn/error counts
- preprocessing completion rate
- runtime
- peak memory / storage

## Scientific-packaging metrics

- derivative metadata completeness
- report completeness
- methods text completeness
- provenance bundle completeness
- rerun success rate

## Comparative metrics

- agreement with upstream baseline outputs where comparison is appropriate
- degree of manual intervention required
- proportion of results that are publication-ready without hand assembly
