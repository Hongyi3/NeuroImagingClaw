# Code of Conduct

ClawNeuro is a scientific software community. We expect contributors to act with professionalism,
respect, and care for the people affected by this work.

## Expected behavior

- be respectful and constructive;
- critique ideas, not people;
- disclose uncertainty honestly;
- welcome contributors from different backgrounds and levels of expertise;
- avoid harassment, intimidation, discrimination, or personal attacks.

## Scope

This applies to repository discussions, pull requests, issues, releases, project communication channels,
and any public interaction where a person is representing the project.

## Enforcement

Maintainers may warn, moderate, limit participation, or remove contributions that violate this policy.
A future public release should replace this placeholder with a finalized community code of conduct and
named reporting contacts.
