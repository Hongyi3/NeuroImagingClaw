# Publication Roadmap

## Goal

Publish ClawNeuro as serious research software, not merely release code.

## Phase 1 — repository readiness
Before any paper submission:
- clean README and docs
- stable catalog and skill schema
- tests and CI
- benchmark manifest
- `CITATION.cff`
- versioned releases

## Phase 2 — DOI-backed releases
Connect GitHub releases to Zenodo.
Each significant release should be archived and citable.

## Phase 3 — JOSS
Target JOSS once:
- installation is straightforward,
- documentation is solid,
- tests are credible,
- research significance is clear,
- the repository reflects mature software practice.

## Phase 4 — domain methods paper
Publish a stronger field-facing paper around:
- standards-native orchestration,
- benchmarked public-data workflows,
- model reproduction,
- interoperability with existing ecosystem tools.

## Phase 5 — community visibility
Prepare:
- reproducible tutorials
- conference demos
- workshop materials
- dataset and model reproduction packs

## Release artifacts checklist

For each release:
- GitHub release notes
- Zenodo DOI
- benchmark summary
- CITATION update if needed
- changelog
- tagged container notes

## RRID preparation

When the software is stable and publicly visible:
- prepare RRID registration / citation guidance
- add RRID to the website and citation instructions once issued
