# Code of Conduct

We are committed to building a welcoming, respectful, and scientifically serious community.

## Our standards

Examples of behavior that contribute to a positive environment:
- using welcoming and inclusive language
- being respectful of differing viewpoints and experiences
- accepting constructive criticism gracefully
- focusing on what is best for the project and the scientific community
- giving credit clearly and generously
- separating critique of ideas from critique of people

Examples of unacceptable behavior:
- harassment or discrimination
- personal attacks
- dismissive or hostile review behavior
- misrepresentation of others' work
- knowingly submitting misleading scientific claims or fabricated benchmarks

## Scope

This code of conduct applies to project spaces, including:
- GitHub issues and pull requests
- discussions
- community chats
- conferences and workshops where the project is represented

## Enforcement

Project maintainers may remove, edit, or reject contributions and communications that violate this code of conduct.

For concerns, contact the maintainers through the private security / conduct channel specified in `SECURITY.md`.
