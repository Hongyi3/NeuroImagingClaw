# Papers and reproduction packs

This directory should hold publication-facing artifacts and exemplar reproduction packs.

## First three recommended packs

1. one NWB / DANDI public neurophysiology workflow
2. one Allen or IBL benchmarked analysis workflow
3. one public computational model reproduction pack

Each pack should contain:
- source metadata
- exact execution commands
- figures
- tables
- report
- environment capture
- citation notes
